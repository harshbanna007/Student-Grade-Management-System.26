# Project Statement

## Project Title

Student Grade Management System

## Problem Statement

Managing student grades manually can be time-consuming and can lead to errors in maintaining student records.

The Student Grade Management System provides a simple Python-based solution for managing student names and grades through a menu-driven interface.

## Scope of the Project

The project focuses on basic student grade management operations.

The system allows users to:

- Add student records
- Update student grades
- Delete student records
- View all student records
- Search for a student
- Validate grade input

## Target Users

The system is intended for:

- Students
- Teachers
- Small educational applications
- Users learning Python programming and CRUD operations

## High-Level Features

1. Student addition
2. Grade updating
3. Student deletion
4. Display of student records
5. Student searching
6. Grade validation
7. Error handling
8. Automated testing
