# Student Grade Management System

## 1. Project Overview

The Student Grade Management System is a Python-based application used to manage student names and their grades.

The system provides basic student management operations such as adding, updating, deleting, displaying, and searching student records.

## 2. Features

- Add a student
- Update a student's grade
- Delete a student
- View all students
- Search for a student
- Validate grades between 0 and 100
- Handle invalid user input
- Unit testing using pytest

## 3. Technologies Used

- Python
- Git
- GitHub
- Pytest
